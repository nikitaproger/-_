### Пояснительная записка к репозиторию курсовой работы «Дерево отрезков»

#### Цель работы
Реализация структуры данных «дерево отрезков» с поддержкой операций запроса суммы, минимума и максимума на отрезке, а также обновления отдельных элементов массива. Цель проекта — продемонстрировать эффективность дерева отрезков для выполнения частых запросов на интервалах массива с логарифмической сложностью.

#### Актуальность
Дерево отрезков — фундаментальная структура данных в алгоритмическом программировании. Она широко применяется:
* в олимпиадных задачах;
* при обработке больших массивов данных;
* в системах аналитики для быстрого вычисления агрегированных показателей;
* в задачах реального времени, где требуется многократное выполнение запросов на отрезках.

Преимущество дерева отрезков перед простым перебором — снижение сложности запросов с $O(n)$ до $O(\log n)$, что критически важно при большом количестве запросов.

#### Реализованные функции
Программа позволяет:
1. Построить дерево отрезков из заданного массива чисел.
2. Выполнить запрос:
    * суммы элементов на отрезке $[l, r]$;
    * минимума на отрезке $[l, r]$;
    * максимума на отрезке $[l, r]$.
3. Обновить значение отдельного элемента массива с автоматическим обновлением дерева.
4. Визуализировать структуру дерева с подсветкой узлов, участвующих в вычислении.

#### Архитектура решения

**Основные компоненты:**

1. **`segment_tree.py`** — ядро программы, реализующее класс `SegmentTree`. Содержит методы:
    * `__init__()` — построение дерева за $O(n)$;
    * `_build()` — рекурсивное построение дерева;
    * `_query()` — выполнение запросов (сумма, минимум, максимум) за $O(\log n)$;
    * `_update()` — обновление элемента за $O(\log n)$.

2. **`app.py`** — графический интерфейс на Tkinter. Обеспечивает:
    * ввод массива и построение дерева;
    * выбор типа запроса (сумма/минимум/максимум);
    * указание границ отрезка для запроса;
    * обновление элементов массива;
    * визуализацию дерева с цветовой индикацией узлов (зелёные — участвуют в ответе, жёлтые — просмотрены).

3. **`test_segment_tree.py`** — набор из 7 автоматических тестов для проверки корректности работы дерева отрезков:
    * тесты на построение дерева;
    * тесты запросов суммы, минимума, максимума;
    * тесты обновления элементов;
    * граничные случаи (массив из одного элемента, запросы на весь массив).

#### Технические характеристики

**Сложность операций:**
* построение дерева: $O(n)$;
* запрос суммы/минимума/максимума на отрезке: $O(\log n)$;
* обновление элемента: $O(\log n)$;
* потребление памяти: $O(n)$.

**Ограничения:**
* визуализация дерева доступна только для массивов размером до 16 элементов (для сохранения читаемости схемы);
* вычисления корректно работают с массивами любого размера.

#### Инструкция по запуску

**Требования:**
* Python 3 (с предустановленным модулем Tkinter);
* сторонние библиотеки не требуются.

**Запуск приложения:**
```bash
python app.py
```
**Использование интерфейса:**
1. В поле **Массив** введите числа через пробел (например, `5 2 8 6 1 4 7 3`).
2. Нажмите **Построить дерево** — отобразится визуализация.
3. Для запроса:
    * укажите границы отрезка (начиная с 1);
    * выберите операцию (сумма, минимум или максимум);
    * нажмите **Найти** — результат появится внизу.
4. Для обновления элемента:
    * введите номер элемента (начиная с 1);
    * укажите новое значение;
    * нажмите **Изменить** — дерево обновится автоматически.

**Запуск тестов:**
```bash
python -m unittest -v test_segment_tree.py
```

* `test_segment_tree.py` — автоматические тесты (7 сценариев).
* `Курсовая.docx` — полная пояснительная записка к курсовой работе.

#### Пример работы
Для массива $[5, 2, 8, 6, 1, 4, 7, 3]$ и запроса суммы на отрезке с 2‑го по 6‑й элемент программа возвращает **21** (элементы: $2 + 8 + 6 + 1 + 4$). На визуализации зелёные узлы входят в вычисление, жёлтые — пройдены при поиске.
