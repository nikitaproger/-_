## Что делает программа

Красно-чёрное дерево — это самобалансирующееся бинарное дерево поиска. Оно хранит числа и автоматически поддерживает баланс при добавлении новых элементов.

Программа поддерживает:
- **Вставку** элементов.
- **Поиск** элементов.
- **Проверку** корректности структуры и свойств красно-чёрного дерева.

## Файлы

- `main.py` — запуск программы и проверка работы дерева.
- `models/node.py` — класс узла дерева.
- `trees/red_black_tree.py` — реализация красно-чёрного дерева.

## Как запустить

Нужен **Python 3**. Сторонние библиотеки не требуются.

```bash
python main.py
```

При запуске выполняется тестирование дерева на массиве чисел: проверяется вставка элементов, поиск существующих и отсутствующих значений, а также корректность структуры дерева.

## Сложность

- Поиск элемента: `O(log n)` в среднем и в худшем случае.
- Вставка элемента: `O(log n)` в худшем случае.
- Память: `O(n)`.

Красно-чёрное дерево автоматически балансируется после вставки с помощью перекрашивания узлов и поворотов.
