# Курсовая работа: красно-чёрное дерево

**Выполнили:** Агрелов Н. В., Маслов В. А., группа 5423, РГРТУ.

## Что делает программа

Красно-чёрное дерево — самобалансирующееся бинарное дерево поиска. Программа поддерживает вставку и поиск элементов, а также проверку структуры и свойств дерева.

## Файлы

- `main.py` — запуск программы и тестирование дерева.
- `interfaces/tree_interface.py` — интерфейс дерева.
- `models/node.py` — класс узла.
- `trees/red_black_tree.py` — реализация красно-чёрного дерева.

## Как запустить

Требуется Python 3. Сторонние библиотеки не нужны.

```bash
python main.py
```
